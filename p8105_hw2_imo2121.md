This is a dataset with 684 rows and 19 columns. It contains station’s
lines, station names, geographic coordinates, what routes each station
serves, whether the station has an entry way, vending, and is ada
compliant, and what sort of entrance type the station uses. The data was
cleaned by using janitor::clean names and changing blank values to NA
for clarity. The entry variable was changed from a character string to a
logical value. The route values were changed to factors, since they were
a mix of characters and integer vectors. Repeated rows were removed. The
data seems tidy, but having a separate column for each route could be
cleaned into one column, creating more rows and making the data easier
to manipulate.
